# 🐕 Quadruped Robot Mechanical Design & Exploded View

## 📌 Project Overview

This project presents the complete mechanical design of a quadruped robot using **Onshape CAD**. The robot was designed with four legs driven by SG90 servo motors to simulate a stable walking mechanism. The project focuses on developing the robot's mechanical structure, assembling all components using engineering mates, and creating a professional **Exploded View** to illustrate how every part fits together.

The exploded view provides a clear visualization of the robot's internal structure and assembly sequence, making it easier to understand the relationship between the chassis, top cover, servo motors, and legs. This project demonstrates the fundamentals of CAD modeling, robotic mechanical design, and engineering documentation.

# 🧩 Mechanical Design

The robot consists of a lightweight rectangular chassis that serves as the main body and supports all internal and external components. Four legs are attached to the body through SG90 servo motors, allowing each leg to rotate and simulate walking motion.

Each leg is composed of multiple mechanical parts connected using revolute joints, enabling smooth movement while maintaining structural stability. The design was created with simplicity, ease of assembly, and future development in mind.

---

# 💥 Exploded View

An Exploded View was created to clearly demonstrate the assembly structure of the quadruped robot. Every component was separated while preserving its original orientation to illustrate how the robot is assembled.

The exploded configuration includes:

- Top Cover
- Main Chassis
- Four SG90 Servo Motors
- Four Robot Legs

This visualization helps engineers understand the relationship between components and simplifies maintenance, assembly, and documentation.

# 🚧 Challenges Faced

Throughout this project, several challenges were encountered during the design and assembly process:

- Designing a compact and balanced chassis.
- Aligning all servo motors accurately.
- Creating robot legs with proper dimensions.
- Applying assembly mates correctly.
- Preventing interference between moving components.
- Organizing the exploded view clearly.
- Maintaining symmetry between all four legs.
- Adjusting component spacing for a clean engineering presentation.
- Ensuring the assembly remained stable after adding all parts.
- Improving the overall appearance of the CAD model.

These challenges helped improve both mechanical design skills and experience with professional CAD assembly techniques.
